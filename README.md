# Mneme
A unified API integration and cross-device synchronization platform, built on top of chat-demo.一个基于chat-demo的统一 API 接入与多设备数据同步平台。




### 项目来源与致谢

Mneme 的初始 Web 聊天界面基于 [DeepSeek ChatDemo](https://github.com/deepseek-ai/chat-demo) 进行二次开发。

本项目在原有实现的基础上，逐步扩展统一 API 接入、数据管理与多设备同步等能力。

感谢 DeepSeek 团队对开源社区的贡献。原项目采用 MIT License，相关版权声明与许可证文本予以保留。

Mneme 是一个独立的社区开发项目，与 DeepSeek 官方无隶属关系。
